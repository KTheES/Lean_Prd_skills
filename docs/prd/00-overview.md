# 00. 제품 개요

| 제품 | 버전 | 최종 수정 | 관련 가설 |
|---|---|---|---|
| ArtGuard | 0.1 | 2026-10-28 | 전체 |

> 기본 가정: 기존 대화의 ArtGuard를 과제 아이디어로 사용, 1인·주 20시간, 월 5만 원, 8주, 반응형 웹, 실제 사용자 데이터 없음, 첫 10명 채널 미확정. 사용자 확정 전 초안이다.

## 1. 한 줄 정의

**온라인에 작품을 공개하는 1인 시각 창작자**가 **유사 상품 후보를 찾고 근거를 정리하기 어려울 때** **ArtGuard**로 **검토 가능한 출처·비교 근거와 다음 행동을 한 리포트에서 얻는다**.

## 2. 비전과 현재 단계

- 비전(3년): 창작자가 자신의 작품 관련 온라인 후보를 투명한 근거로 검토하고 주도적으로 대응하는 도구
- 현재 단계: 문제 검증 전, MS0/E1 준비
- 범위: 8주 MS0~MS3 계획 중 실제 수행 대상은 Cycle 1의 MS0
- 제품 경계: 유사 후보를 제시하며 저작권 침해 여부를 자동 판정하지 않는다.
