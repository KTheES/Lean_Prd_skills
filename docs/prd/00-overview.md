# 00. 제품 개요

| 제품 | 버전 | 최종 수정 | 관련 가설 |
|---|---|---|---|
| ArtGuard | 0.2 | 2026-10-30 | 전체 |

> 확정 사항: 사용자는 2026-10-28 ArtGuard를 과제 아이디어로 승인했고, 2026-10-30 실제 면담 5건을 근거로 P1 Customer Segment Pivot을 승인했다. 운영 가정은 1인·주 20시간, 월 5만 원, 8주, 반응형 웹이다.

## 1. 한 줄 정의

**캐릭터·창작 굿즈의 진위·출처를 월 1회 이상 확인하는 소비자**가 **공식 여부가 불분명한 상품을 발견했을 때** **ArtGuard**로 **공식 출처·판매자·시각적 차이·불확실성과 다음 행동을 한 리포트에서 얻는다**.

## 2. 비전과 현재 단계

- 비전(3년): 굿즈 생태계 참여자가 불분명한 상품을 투명한 근거로 검토하고 주도적으로 판단하는 도구
- 현재 단계: Cycle 1/MS0 완료, Pivot(P1) 반영, MS1/E2 실제 행동 검증 준비
- 범위: 8주 MS0~MS3 중 MS0 완료. 다음 수행 대상은 상품 URL 기반 수동 리포트 E2다.
- 제품 경계: 유사 후보를 제시하며 저작권 침해 여부를 자동 판정하지 않는다.
