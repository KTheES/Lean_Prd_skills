# 03. 솔루션과 MVP

| 제품 | 버전 | 최종 수정 | 관련 가설 |
|---|---|---|---|
| ArtGuard | 0.2 | 2026-10-30 | H1, H2 |

## 1. 솔루션 개요

- 고유 가치 제안: 사고 싶은 굿즈의 진위·출처 확인 근거를 “침해 판정”이 아닌 공식 출처·판매자·시각적 차이 리포트로 정리한다.
- 핵심 흐름: 상품 URL·이미지 제시 → 사람이 공식 목록·판매자·시각적 차이 확인 → 근거와 불확실성을 리포트로 제공 → 사용자가 저장·원문 방문·추가 검토 선택
- 차이: 후보 링크 수보다 출처·수집 시각·유사 근거·사용자 행동을 한 문서로 연결한다.

## 2. MVP 유형과 선택 이유

- 유형: MS0 Landing page, MS1 Concierge/Wizard of Oz
- 이유:
  1. H1은 코드 없이 인터뷰와 신청 행동으로 먼저 검증할 수 있다.
  2. H2는 모델을 구축하기 전에 사람이 후보와 근거를 정리해 리포트 가치만 10영업일 안에 검증할 수 있다.
  3. 자동 탐지 정확도와 대규모 크롤링은 가치 확인 전 비용·법적 위험이 커서 제외한다.
- 진화: MS0 Landing page → MS1 Concierge → MS2 Single-feature → MS3 초대 채널 실험

## 3. MVP 범위 (In / Out)

| 기능 | In/Out | 검증 가설 | 비고 |
|---|---|---|---|
| 문제 인터뷰·후속 테스트 신청 | In | H1 | M1 측정 |
| 상품 URL·샘플 이미지 제출 안내와 동의 | In | H2 | 최소 동작·개인정보 경계 |
| 사람이 정리한 공식 출처·판매자·시각적 차이 리포트 | In | H2 | Concierge 방식, 판단과 근거·불확실성 분리 |
| 저장·추가 검토·원문 이동 선택 | In | H2 | 측정 장치, M2 측정 |
| 자동 다중 마켓 크롤링 | Out | — | H2 통과와 합법적 수집 근거 확인 후 재검토 |
| 자동 저작권 침해 판정 | Out | — | 유사도는 법률 판단이 아니므로 제품 범위에서 제외 |
| 소셜 로그인·프로필 수정 | Out | — | 핵심 가설과 무관, MS2 리텐션 필요 시 최소 인증 재검토 |
| 유료 결제 | Out | — | H1·H2 통과 후 가격 실험에서 재검토 |

구축 기간 추정(1인): 랜딩·양식 2일, 수동 리포트 템플릿 2일, 분석·테스트 2일, 참여자 대응 4일 = 10영업일

## 4. MVP 성공 기준

- M1 문제 적합·후속 참여율 ≥ 60% (소비자 인터뷰 5명 중 3명 이상). Cycle 1 실측 5/5=100%.
- M2 리포트 행동 선택률 ≥ 50% (리포트 열람자 기준)
- 실패: M1 < 40%이면 P1, M2 < 30%이면 P2를 검토한다.
