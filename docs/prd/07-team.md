## 3. 채용 / 외주 우선순위

1. 도메인/법률 자문 — MS1 리포트 문구와 증거 보존의 위험을 낮춤 — H1 통과 직후 — 1회 자문 예산 확인 필요
2. ML/검색 자문 — MS2 자동화 전 평가 데이터와 오탐 한도를 설계 — H2 통과 후 — 시간 단위 자문 예산 확인 필요
3. UI 접근성 검토 — 실제 참여자의 폼·리포트 사용 장애를 줄임 — MS2 전 — 소규모 외주 검토

## 4. 의사결정 규칙

- 지표 리뷰: 매주 금요일 30분, 05 지표와 익명 인터뷰 요약을 입력으로 사용한다.
- Pivot/Persevere: PM이 임계값 기반 제안을 만들고 제품 책임자인 학생이 승인한다. 불일치 시 10 §2 숫자 T#를 우선한다.
- 범위 추가: H# 또는 측정 장치 사유가 없는 기능은 MVP 백로그에 넣지 않는다.
- 실험 WIP 제한: 동시에 1개. 작은 팀에서 데이터 해석과 운영 혼선을 막는다.
- 안전 결정: 법률 판단·개인정보 보관 방식은 자문 또는 공식 근거가 없으면 보수적으로 Out 처리한다.
