## 2. Pivot 트리거

| 트리거 | 조건 | 연결 옵션 |
|---|---|---|
| T1 | M1 < 40%가 1사이클이고 적합 표본이 5명 이상 | P1 |
| T2 | M2 < 30%가 1사이클 또는 M4 < 20%가 2사이클 연속 | P2 |

## 4. Kill 조건

- P1로 전환한 소비자 세그먼트의 후속 표본에서도 M1 < 40%이고 월 1회 이상 문제 경험이 2명 미만이면 문제 비전을 중단한다.
- P2 이후에도 M2 < 30%가 2사이클 연속이고 정성 피드백에서 리포트 근거가 행동에 도움이 되지 않으면 솔루션 비전을 중단한다.
- 합법적 데이터 수집·보관 경로를 확보할 수 없거나 참여자 삭제 요구를 24시간 안에 처리할 수 없으면 관련 실험을 즉시 중단한다.
