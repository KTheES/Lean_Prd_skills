## 2. Pivot 트리거

| 트리거 | 조건 | 연결 옵션 |
|---|---|---|
| T1 | M1 < 40%가 1사이클이고 적합 표본이 5명 이상 | P1 |
| T2 | M2 < 30%가 1사이클 또는 M4 < 20%가 2사이클 연속 | P2 |
| T3 | M3 < 10%가 2개 채널에서 각각 1사이클 | P3 |

## 3. 사전 정의된 Pivot 옵션

| ID | 유형 | 우리 제품에서는 구체적으로 | 유지되는 것 | 버리는 것 | 예상 비용 |
|---|---|---|---|---|---|
| P1 | Customer Segment | 일반 1인 창작자에서 굿즈 판매 경험과 과거 도용 대응 경험이 있는 창작자로 좁힘 | 근거 정리 문제 | 광범위 모집 | 인터뷰 5건 추가, 1주 |

| P3 | Channel | 공개 커뮤니티 공유에서 신뢰 기반 1:1 동료 초대로 전환 | H1/H2 가치와 초대 링크 | 공개 홍보 문구 | 채널 인터뷰·문구 실험 1주 |

## 4. Kill 조건

- P1로 좁힌 두 번째 세그먼트에서도 M1 < 40%이고 월 1회 이상 문제 경험이 2명 미만이면 문제 비전을 중단한다.
- P2 이후에도 M2 < 30%가 2사이클 연속이고 정성 피드백에서 리포트 근거가 행동에 도움이 되지 않으면 솔루션 비전을 중단한다.
- 합법적 데이터 수집·보관 경로를 확보할 수 없거나 참여자 삭제 요구를 24시간 안에 처리할 수 없으면 관련 실험을 즉시 중단한다.
