## Cycle 0 — 초기 가정 (2026-10-28)

- 확정 사항: 사용자는 2026-10-28 ArtGuard를 제출 아이디어로 승인함
- 운영 가정: 1인 주 20시간, 월 5만 원, 8주, 반응형 웹, 첫 접근 채널 미확정
- 가설 스냅샷: H1 문제·후속 참여 / H2 리포트 행동 가치·재확인 / H3 동료 초대 성장
- 사용자가 제공한 기존 데이터: 없음. 과거 프로젝트 구현 사실을 사용자 반응으로 간주하지 않음.
- 1순위 실험: E1(H1) — MS0
- 증빙 준비: `experiments/cycle-1/`에 동의문·인터뷰·집계·분석 빈 양식 생성

## Cycle 1 — E1/H1 실제 면담 (2026-10-30)

- **Build**: E1/H1 설문 GUI와 샘플 리포트를 통해 문제 빈도·후속 참여 의향·리포트 평가를 비식별 수집.
- **Measure**: 실제 참여자 5명(P01~P05). 기존 H1의 창작자 적합 표본은 3명(P02~P04), 이들의 M1은 3/3=100%. 단, 사전 최소 적합 표본 5명을 채우지 못함.
- **Learn**: 전체 5명은 모두 월 1회 이상 유사 굿즈 진위·출처 확인 문제와 후속 참여 의향을 보였다. 반복 요구는 공식 라이선스, 판매자·판매처, 시각적 차이의 근거였고 최대 신뢰 위험은 진품을 가품으로 보는 오탐이었다.
- **E2 proxy**: 저장·원문 방문·추가 검토 선택은 3/5=60%였다. 실제 `evidence_action_selected` 이벤트가 아니므로 H2/E2 통과 근거로 사용하지 않는다.
- **결정**: Pivot(P1) — 1차 타깃을 월 1회 이상 진위·출처를 확인하는 캐릭터/창작 굿즈 소비자로 전환하고 창작자를 2차 세그먼트로 유지한다.
- **결정 상태**: 제품 책임자(학생)가 2026-10-30 승인했고, PRD 00~11의 고객·가설·MVP·지표·실험·팀·기술·마일스톤·리스크에 반영했다.
- **증빙**: `experiments/cycle-1/responses.csv`, `participants/`, `summary.md`, `analysis-template.md`
- **한계**: 지인 표본, 소표본, 자기보고, 실제 행동 이벤트 미측정.
