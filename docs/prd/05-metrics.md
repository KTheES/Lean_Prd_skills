## 1. North Star Metric

- NSM: **주간 근거 기반 후속 행동을 선택한 굿즈 소비자 수** — 해당 주 리포트에서 저장·추가 검토·원문 이동 중 하나를 선택한 고유 소비자 수
- 이유: 검색 결과 노출이 아니라 사용자가 대응 가능한 근거를 얻었는지를 나타낸다.
- 현재: 측정 전 → MS3 목표: 주 20명. 초기 가정이며 Cycle 1 이후 보정한다.

## 3. Actionable vs Vanity

| 보지 않을 숫자 (Vanity) | 이유 | 대신 볼 것 |
|---|---|---|
| 누적 페이지뷰 | 반복·봇 유입을 포함하고 문제 해결 행동을 설명하지 못함 | M1, M2 |
| 누적 업로드 수 | 같은 사용자의 반복과 가치 획득을 구분하지 못함 | M2, M4 |
| 검색 후보 총수 | 후보가 많을수록 오탐과 검토 부담이 커질 수 있음 | 후속 행동 선택과 정성 신뢰 피드백 |

## 4. 측정 방법과 이벤트

- 도구: MS0은 익명 CSV 집계, MS1부터 PostHog 제품 분석·Feature Flag
- 수집 주기: 실험 종료 시 수동 검증, 이후 일 1회 집계

| 이벤트 이름 | 지표 | 발생 시점 | 속성 |
|---|---|---|---|
| `landing_viewed` | M1 | 랜딩 진입 | source, anonymous_id |
| `waitlist_submitted` | M1 | 후속 테스트 신청 | source, consent |
| `report_opened` | M2, M4 | 결과 리포트 열람 | report_id, cohort_week |
| `evidence_action_selected` | M2 | 저장·검토·원문 이동 선택 | report_id, action_type |
| `followup_returned` | M4 | 7일 이내 재방문 | cohort_week, days_since_first |
| `invite_opened` | M3 | 초대 링크로 진입 | invite_id, referrer_anonymous_id |
