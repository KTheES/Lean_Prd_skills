# 04. 요구사항

| 제품 | 버전 | 최종 수정 | 관련 가설 |
|---|---|---|---|
| ArtGuard | 0.1 | 2026-10-28 | H1, H2 |

범위는 `03-solution-and-mvp.md`의 In 항목으로 제한한다.

## 1. 사용자 스토리

| ID | 스토리 | 수용 기준 | 검증 가설 |
|---|---|---|---|
| US1 | 1인 창작자로서 문제 경험을 설명하고 후속 테스트를 신청하고 싶다, 그래야 내 상황에 맞는 검증에 참여할 수 있다. | Given 안내와 동의가 보일 때, When 필수 응답을 제출하면, Then 익명 참여 ID와 철회 방법이 표시된다. | H1 |
| US2 | 테스트 참여자로서 후보의 출처와 비교 근거를 보고 싶다, 그래야 다음 대응을 판단할 수 있다. | Given 수동 리포트가 준비됐을 때, When 링크를 열면, Then 후보별 URL·수집 시각·비법률적 유사 근거가 보인다. | H2 |
| US3 | 테스트 참여자로서 리포트에서 후속 행동을 선택하고 싶다, 그래야 필요한 증거를 다시 찾을 수 있다. | Given 리포트를 열었을 때, When 저장·추가 검토·원문 이동을 선택하면, Then 선택 이벤트가 익명 ID와 기록된다. | H2 |

## 2. 기능 요구사항

| ID | 요구사항 | 관련 스토리 | 우선순위 |
|---|---|---|---|
| FR1 | 문제 빈도와 후속 참여 동의를 수집한다. | US1 | Must |
| FR2 | 샘플 이미지 제출 목적·보관·삭제 방법을 표시한다. | US2 | Must |
| FR3 | 후보를 최대 3개로 제한하고 출처 URL·수집 시각·비교 설명을 표시한다. | US2 | Must |
| FR4 | 후속 행동 세 가지와 이벤트 기록을 제공한다. | US3 | Must |

## 3. 비기능 요구사항

| 영역 | 요구사항 |
|---|---|
| 성능 | 정적 랜딩 p95 첫 화면 2초 이내, 리포트 p95 3초 이내를 개발자 도구로 확인한다. |
| 보안·개인정보 | API 키를 클라이언트에 두지 않고, 공개 결과에는 익명 ID만 사용하며, 삭제 요청은 24시간 이내 처리한다. |
| 접근성 | 키보드만으로 신청·행동 선택 가능, 폼 라벨 제공, 텍스트 대비 WCAG 2.1 AA 목표를 수동 점검한다. |
| 제품 경계 | 유사 후보는 참고 정보이며 저작권 침해의 자동 법률 판단이 아님을 리포트 상단에 표시한다. |
| 분석 이벤트 | 아래 이벤트 집합을 `05-metrics.md` §4와 동일하게 사용한다. |

| 이벤트 이름 | 발생 시점 | 속성 |
|---|---|---|
| `landing_viewed` | 랜딩 진입 | source, anonymous_id |
| `waitlist_submitted` | 후속 테스트 신청 | source, consent |
| `report_opened` | 결과 리포트 열람 | report_id, cohort_week |
| `evidence_action_selected` | 후속 행동 선택 | report_id, action_type |
| `followup_returned` | 7일 이내 재방문 | cohort_week, days_since_first |
| `invite_opened` | 초대 링크 진입 | invite_id, referrer_anonymous_id |

## 4. 우선순위 (MoSCoW)

| 등급 | 항목 |
|---|---|
| Must | 인터뷰·신청, 이미지 제출 안내·동의, 수동 후보 리포트, 후속 행동 선택·측정 |
| Should | 리포트 PDF 내보내기, 후보 정렬 |
| Could | 이메일 알림, 즐겨찾기 |
| Won't (이번 범위) | 자동 크롤링, 자동 침해 판정, 소셜 로그인, 프로필 수정, 결제 |
