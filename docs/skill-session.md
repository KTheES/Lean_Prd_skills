# Skill 실행 기록

## 실행 환경

- 실행 도구: OpenAI Codex desktop
- Skill 규격: Claude Code 프로젝트 로컬 Agent Skill (`.claude/skills/lean-prd/`)
- 실행일: 2026-10-28
- 주의: Codex에서는 `/lean-prd` 명령을 직접 호출하지 않고 `SKILL.md`와 참조 문서를 읽어 동일 절차를 수행했다. 최종 제출 전 Claude Code에서 트리거 재현 확인이 필요하다.

## 입력

사용자가 새 과제 저장소와 과제 명세·스타터 킷·인계 문서를 제공했다. 인계 문서의 제품 아이디어 입력란은 비어 있었다.

기존 대화에서 확인된 프로젝트 맥락을 바탕으로 다음을 **초기 가정**으로 사용했다.

- 제품명: ArtGuard
- 아이디어: 창작자가 이미지를 업로드하면 온라인 판매 상품 중 유사 후보를 찾아 비교 근거와 리포트를 제공한다.
- 팀/시간: 1인, 주 20시간
- 예산: 월 5만 원
- 플랫폼: 반응형 웹
- 실사용자 데이터: 제공되지 않음
- 첫 10명 채널: 미확정

제품 가정은 사용자 확정 전이므로 `00-overview.md`와 `11-bml-log.md`에 명시했다.

## 최대 5개 확인 질문

1. 제품명·한 줄 아이디어·현재 대안은 무엇인가?
2. 첫 잠재고객 10명과 접근 채널은 무엇인가?
3. 이미 확보한 실제 데이터와 재사용 자산은 무엇인가?
4. 팀 규모·주당 시간·월 예산·기간은 얼마인가?
5. 플랫폼 제약과 가장 걱정되는 가정은 무엇인가?
