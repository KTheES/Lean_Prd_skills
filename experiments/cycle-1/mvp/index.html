ArtGuard는 유사 후보를 법률적으로 판정하지 않습니다. 대신 후보의 출처, 수집 시각, 비교 근거를 한 리포트로 정리해 창작자가 다음 행동을 검토하도록 돕는 서비스 아이디어입니다.

실험 방식 보기

이 페이지는 수요를 검증하는 과제용 MVP입니다. 버튼은 서버로 개인정보를 전송하지 않으며, 실제 참여 신청은 연구자가 별도 동의 절차로 진행해야 합니다.

1. 문제 확인

최근 확인 경험과 현재 대응 시간을 익명 인터뷰로 듣습니다.

2. 수동 리포트

자동 모델보다 먼저 사람이 후보와 근거를 최대 3개로 정리합니다.

3. 행동 측정

리포트가 실제 다음 행동에 도움이 되는지 사전 기준으로 판단합니다.
