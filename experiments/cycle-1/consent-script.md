# 실험 참여 안내문

이 실험은 창작자가 온라인 유사 상품 탐지·근거 정리 서비스에 실제 관심과 사용 의향이 있는지 확인하기 위한 과제 연구입니다.

- 참여 시간: 약 10~15분
- 수집 항목: 익명 참여자 ID, 창작 활동 맥락, 현재 대응 방식, 랜딩/프로토타입 반응, 자유 의견
- 수집하지 않는 항목: 실명, 계정 비밀번호, 주민등록번호, 불필요한 연락처
- 사용 목적: 수업 과제의 집계 분석 및 제품 가설 검증
- 공개 범위: 개인을 식별할 수 없는 집계값과 익명 인용만 GitHub에 공개
- 중단·삭제: 참여자는 언제든 중단하거나 자신의 기록 삭제를 요청할 수 있음
